Aberrations - Zygo Controller / LEnsE

From interferogram to aberrations

This application allow to control the acquisition of interferogram (via a Zygo interferometer), to display the wavefront and to access to Zernike decomposition.

ZYGO is a Fizeau laser interferometer(using an amplitude division) equipped with a phase shift system.

Labwork subject can be found by this link : https://lense.institutoptique.fr/s8-aberrations/
